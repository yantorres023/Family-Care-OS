# Brand (provisional)

## Working name: **Baton**
Tagline candidates:
- "Pass the baton. Keep Mom's care on track."
- "Who's doing what for Mom — sorted."
- "The family to-do list for a parent's care."

Rationale: relay/handoff metaphor matches the core loop (claim → do → hand off); short; not medical; not cutesy; works in US/UK/CA English.

## Naming research (web search, 2026-09-25)
| Candidate | Findings | Status |
|---|---|---|
| Family Care OS | Many "Family Care" apps (Samsung parental control, Braun thermometer app, KMCC membership, FamilyCare health-data app); "Family OS" (India pregnancy/family app). Generic and implies health. | Rejected |
| Baton | No caregiving app named Baton found in searches. "Baton" is a common word used by unrelated companies (e.g., fintech). | **Provisional — trademark clearance required** |
| Kinrota | No app found; "rota" is UK-only vocabulary. | Backup (UK) |
| Tended | No app found; "tendercare" exists in elder care (confusing). | Rejected |
| Relay / Handoff | Apple "Handoff" feature; generic. | Rejected |

**Human action:** USPTO/UKIPO/CIPO search in classes 9 and 42 for "Baton", App Store/Play name availability, domain (e.g., batonfamily.app). The store listing name may need a descriptor: "Baton: Family Care To-Dos".

## Voice
Warm, practical, brief. Talks like a capable sibling, not a nurse or a bank. Never promises health outcomes. Uses "needs someone", "I'll do it", "note for the next person".

## Visual
Terracotta seed colour (#8A4B2F) with Material 3 tonal palette; avoids clinical blue/green, red crosses, stethoscopes, heart-rate lines. Icon concept: a simple relay baton or two hands passing a card.

## Claims we must never make
"Improves health", "prevents falls/hospitalisation", "medication management", "HIPAA compliant" (not applicable/unverified), "trusted by X families" (no users yet), any testimonial.
